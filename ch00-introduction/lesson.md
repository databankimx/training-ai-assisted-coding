# Introduction

Welcome to the AI-assisted coding course. You can open a terminal, you can open an editor, and you have probably already typed something into an AI chat window. That's a good start, and it's all the course asks for.

This course teaches you to use AI coding assistants well. It covers what they're good at, where they go wrong, how to ask them for what you actually need, and how to check what they give you before anything reaches a colleague's code review. It also covers the company rules that apply every time you use one, because the rules matter more than any single tool.

The course is for everyone at DataBank. Developers, analysts, trainers, and anyone else who writes or reviews code are all welcome here. The principle is simple: anyone can do development, but everyone follows the rules. This course teaches both halves of that sentence.

## What this chapter covers

Chapter 0 is the starting point. It has five steps before the summary:

1. **What an assistant does when it writes code.** A short explanation of what is happening behind the chat window, with enough detail to make the rest of the course make sense.
2. **What this course covers.** The scope, the structure, and what you can expect from each chapter.
3. **You own the code.** The rule that every other chapter depends on.
4. **Getting Copilot running.** How to set up GitHub Copilot in Visual Studio 2026 or VS Code, and how to prove it works.
5. **Confidential data and company accounts.** The company AI policy in practical terms.

The chapter ends with a summary and three quizzes. There is no homework in this chapter. The only practice is the proof checks in step 4, and you should do those on your own machine.

## How the lessons work

Each lesson is a step. Steps are short enough to read in one sitting, and most end with a small "Try it" section. Each chapter ends with a summary and quizzes. The runner lets you move between steps with the Next button, even when a step belongs to a different chapter.

Chapter 0 has no code to run, so the runner shows the lesson text only. Later chapters will ask you to run code in several languages, and the lessons will explain what you need when you get there.

Take your time. Nothing in the chapters before the capstone is graded. The capstone has a rubric for review, which Chapter 17 explains. If you want feedback on your work later, you can ask for an optional review from the development team, if you're an employee.
