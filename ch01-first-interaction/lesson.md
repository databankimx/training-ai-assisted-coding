# First Interaction

In this chapter you use an AI coding assistant on something small, check its answer, and fix it when it's wrong. Nothing here is big. A function that adds two numbers, a function that counts words, and a function that picks out prime numbers are enough to show every habit the rest of the course depends on.

The goal is not the code. The goal is the habit of reading before you accept. An assistant can produce a correct function in seconds, and it can produce a plausible-looking wrong one in exactly the same time. Your job is to tell which one you have, and you can only do that by checking.

## What you'll do

The chapter has four steps before the summary:

1. **Set up and check your tools.** You confirm that your assistant is working, signed in with a company-provided account, and ready for practice.
2. **Let the assistant finish a small function.** You type the start of a method, pause, and see what it suggests.
3. **Read before you accept.** You learn what pressing Tab means, and you check a suggestion against examples before you keep it.
4. **Reject, refine, or write it yourself.** You learn what to do when the suggestion is wrong, and when it's faster to type the code.

Each step has worked examples you can follow, and a "Try it" section with something for you to do on your own machine. Do the "Try it" sections. Reading about a habit is not the same as practicing it.

## What you'll need

- Visual Studio 2026 or VS Code, with GitHub Copilot signed in, as set up in Chapter 0, step 4.
- A company-provided AI account for any work-related use. The practice in this chapter uses invented examples only, so the free tier is fine for learning.
- A practice folder for your own files. Put it under `C:\Development`, outside any repository you use for work. You'll keep every practice file here, including your own versions of the examples.
- Any one of the three languages in this course: C#, Python, or JavaScript. You can switch between them in the runner's Source tab at any time, and the examples in each step are shown in all three.

## A note on examples

Every code example in this chapter appears in C#, Python, and JavaScript. The runner shows the language you choose in the Source tab, and the lesson text follows the same choice, so the example you read is the one you see in the editor.

The examples are short on purpose. Long examples hide the habit you're trying to learn. When you finish a step, you should be able to say what the code does without looking at it.
